# AI Tools Usage Summary – LandConnect

## 1. Overview

AI-assisted tools were used during the development of the LandConnect mobile application to support development, debugging, documentation, and problem-solving.

The application architecture, implementation, integration, testing, and final development decisions were handled as part of the project development process.

## 2. AI Tools Used

### ChatGPT
ChatGPT was used as a development assistance tool for:

- Understanding React Native, Expo, Node.js, and Express.js concepts.
- Discussing application architecture and implementation approaches.
- Troubleshooting backend and mobile application errors.
- Understanding REST API integration.
- Assistance with database queries and configuration.
- Debugging authentication and JWT-related issues.
- Guidance for Cloudinary image integration.
- Understanding LiveKit audio/video calling integration.
- Assistance with project documentation and setup instructions.

### AI-Assisted Problem Solving

AI assistance was also used to:
- Understand error messages and possible solutions.
- Review implementation approaches.
- Break complex development tasks into smaller steps.
- Improve understanding of unfamiliar libraries and configurations.

## 3. Development Areas Where AI Assistance Was Used

| Development Area | Type of AI Assistance |
|---|---|
| React Native and Expo | Understanding components, navigation, and mobile configuration |
| Node.js and Express.js | Backend implementation guidance and debugging |
| MySQL / TiDB Cloud | Database configuration and query assistance |
| Authentication | Understanding JWT and password hashing |
| Cloudinary | Upload and image URL integration guidance |
| LiveKit | Audio/video calling integration guidance |
| Socket.IO | Understanding communication events |
| Deployment | Troubleshooting Render and EAS configuration |
| Documentation | Structuring technical documentation and setup instructions |

## 4. How AI Suggestions Were Used

AI-generated explanations and suggestions were reviewed and applied where relevant.

During development:
1. Errors were investigated using error messages and application behavior.
2. AI assistance was used to understand possible causes and solutions.
3. Suggested changes were reviewed and adapted to the existing project.
4. Application workflows were tested after implementation.
5. Configuration and integration issues were resolved through iterative debugging.

AI assistance was used as a supporting development resource rather than as a replacement for implementation and testing.

## 5. Verification and Testing

The application was tested to verify its main workflows, including:

- Registration and login.
- Land listing functionality.
- Cloudinary image display.
- Embedded map.
- Meeting-room creation and joining.
- Messaging and chat.
- Audio and video calling across two devices.

## 6. Responsible Use of AI

- AI suggestions were reviewed before applying them.
- Application behavior was tested after implementation.
- Sensitive credentials and API secrets were kept out of the public repository.
- AI-generated suggestions were not treated as proof that a feature worked; features were verified through testing.

## 7. Conclusion

AI tools, particularly ChatGPT, supported the development process by helping with technical understanding, debugging, integration guidance, and documentation.

The tools were used to improve development efficiency and solve technical challenges while the final application was tested through actual mobile workflows.
